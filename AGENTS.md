# Repository instructions

Before working in this repository, read [`HANDOFF.md`](HANDOFF.md) for the current project state, safe-working rules, and deployment context. After every code, database, configuration, or deployment change, update `HANDOFF.md` with a Dhaka-local timestamp, the changes made, verification results, deployment status, and remaining work before reporting completion.

For web-app changes, also follow [`web/AGENTS.md`](web/AGENTS.md) and read the relevant Next.js documentation from `web/node_modules/next/dist/docs/` before editing code.
